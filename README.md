# Aero Client

A fast, lightweight desktop client for [Kirka.io](https://kirka.io), with performance settings, mods, weapon tweaks, sound packs, custom CSS and a resource swapper.

This repo only hosts release builds. The source code is closed.

**Website:** [aeroclient.xyz](https://aeroclient.xyz) · **Discord:** [discord.gg/nYUDxcAjmn](https://discord.gg/nYUDxcAjmn)

## Download

**Latest beta: [v0.1.0-beta.1](https://github.com/d4ym1an/aero-client-releases/releases/tag/v0.1.0-beta.1)** (Windows 64-bit)

Download `aero-client-0.1.0-beta.1-setup.exe` from the release page. That's the only file you need; the others are used by the auto-updater.

Every version is listed on the [Releases page](https://github.com/d4ym1an/aero-client-releases/releases).

> Aero is still in beta, so expect a few bugs. macOS and Linux builds aren't available yet.

## Installing

1. Download and run the setup `.exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. This shows up because the installer isn't code-signed yet.
3. In game, press **Right Shift** to open the client menu.

Aero checks for updates every time it starts and installs them when you close it, so you only need to install it once.

## Switching from another client

Open the menu and go to **Settings → Client → Import from Another Client**. It brings over your settings, game settings, swapper files, scripts and CSS from Juice, Dawn and similar clients, and can keep you signed in after you confirm.

Coming from the old Aero beta (v0.0.0-1)? It shows up in that list as **Aero Client (previous version)**. Once you've imported, you can uninstall the old beta from **Windows Settings → Apps**.

## Features

- **Settings**: HUD, performance (unlimited FPS with an FPS cap), startup, hotkeys and menu appearance
- **Mods**: built-in features plus your own userscripts
- **Weapons**: per-weapon size, position, rotation and weapon bob
- **Sounds**: build, import and export sound packs
- **CSS**: custom game stylesheets from a file or a link
- **Resource swapper** and **Discord Rich Presence**
